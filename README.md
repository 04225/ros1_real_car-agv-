ROS1-notice
Navigation and positioning are achieved using an Arduino-Mega2506 and two P30 motors. The system is equipped with a WS2812B full-color LED strip and Xbox controller remote control functionality. In the near future, I will upload a six-axis robotic arm compatible with MoveIt to integrate it with this system, thereby realizing an ROS-AGV robot for automatic cargo transportation.
Meanwhile, I will push the PCB schematic diagrams and STM32 code to this repository. For more information, please visit www.younger.team. If you are interested in this repository, please give it a star. Thank you very much.
